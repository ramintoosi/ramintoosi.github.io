<h3> Abstract </h3>
Event detection is an important step in extracting knowledge from the video. This paper presents a multi-stage deep learning method for detecting soccer events with three modules: (i) a variational autoencoder (VAE) no-highlight detection module to filter irrelevant scenes, (ii) an EfficientNet-based image classification module for main event recognition, and (iii) a fine-grain attention module to distinguish yellow and red cards. The work introduces the Soccer Event (SEV) dataset with 60,000 balanced images across ten categories, and evaluates the system on full matches from multiple leagues. Experiments demonstrate competitive event detection accuracy with real-time performance under realistic broadcast conditions.
