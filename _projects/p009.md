An open-source remote video monitoring system for rodents housed in Faraday cages, built to support behavioural neuroscience experiments.

The system runs on Raspberry Pi cameras with a Flask server and a web interface for recording, live viewing, and camera parameter control. Recordings and session metadata are stored in a database, and the services are managed through systemd so that acquisition continues reliably over long experimental sessions without manual intervention.

The project addresses the practical side of behavioural data collection: recording control, laboratory constraints, usable interfaces for experimenters, and integration of software with existing experimental workflows.
